# موقع الاختبارات الجامعية 🎓

موقع ويب شامل لإنشاء وإجراء الاختبارات الجامعية مع إمكانية إدارة الأسئلة وعرض النتائج.

## المميزات ✨

- **واجهة مستخدم عربية**: تصميم كامل باللغة العربية مع دعم RTL
- **إجراء الاختبارات**: نظام اختبارات تفاعلي مع مؤقت زمني
- **إدارة الأسئلة**: إضافة وحذف أسئلة الاختبارات بسهولة
- **عرض النتائج**: عرض فوري للدرجات مع مراجعة تفصيلية للإجابات
- **تخزين محلي**: حفظ الأسئلة والنتائج في المتصفح
- **تصميم متجاوب**: يعمل على جميع الأجهزة (هاتف، تابلت، كمبيوتر)

## البدء 🚀

### التشغيل المباشر

1. افتح ملف `index.html` في متصفح الويب
2. استكشف الصفحة الرئيسية
3. انتقل إلى صفحة "إدارة الأسئلة" لإضافة أسئلة جديدة
4. ابدأ الاختبار من صفحة "الاختبارات"

### استخدام خادم محلي (اختياري)

```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx http-server -p 8000
```

ثم افتح المتصفح على `http://localhost:8000`

## كيفية الاستخدام 📖

### إضافة أسئلة جديدة

1. انتقل إلى صفحة "إدارة الأسئلة"
2. املأ نموذج السؤال:
   - نص السؤال
   - الخيارات الأربعة
   - اختر الإجابة الصحيحة
3. اضغط "إضافة السؤال"

### إجراء اختبار

1. انتقل إلى صفحة "الاختبارات"
2. أجب على الأسئلة واحداً تلو الآخر
3. استخدم أزرار التنقل للتحرك بين الأسئلة
4. اضغط "إنهاء الاختبار" لعرض النتائج

### عرض النتائج

- يتم عرض آخر 5 نتائج على الصفحة الرئيسية
- يتم حفظ جميع النتائج في المتصفح
- مراجعة تفصيلية للإجابات بعد إنهاء الاختبار
